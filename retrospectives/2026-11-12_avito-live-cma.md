# Ретроспектива сессии: 2026-11-12_avito-live-cma

1. **Какая задача стояла:**
   - СМА показывает оценку по аналогам из `analog_listings`, но данные в Neon устарели (последний `last_seen_at` - 2026-06-24). Нужно парсить живые объявления Авито по образцу проекта `D:\CODING\avito-parser`, сохранять характеристики и ссылки в таблицу и считать среднюю цену оттуда.

2. **Как решали:**
   - Проверили базу: `analog_listings` в Neon, 733 строки, 531 по Кирову, все без координат, давность 5 месяцев.
   - В `avito-parser/parser.py` добавили инкрементальный режим: параметры `known_ids`, `stop_after_idle_pages`, `meta` (страницы, completed), защиту от `document.body = null`.
   - Создали `avito-parser/realtor_db.py`: схема `analog_listings` + `analog_price_history`, индексы, upsert по `(source, source_id)`, деактивация снятых, реконнект при обрыве Neon.
   - Создали `avito-parser/realtor_sync.py`: 5 категорий (вторичка, новостройки, комнаты, дома, гаражи), пагинация `?p=N`, нормализация цены/площади/комнат/этажа/района, защита от мусора, CLI и режим цикла.
   - В `api/ai-proxy.js` СМА переведена на свежие данные: `last_seen_at` за `CMA_FRESH_DAYS` (30), убран жёсткий `source='AVITO'`, добавлены `sample_size`, `data_as_of`, `data_stale`, fallback на устаревший кэш.
   - В `src/components/CmaReport.jsx` добавлена строка "В выборке: N объявлений · обновлено <дата>".

3. **Результат:**
   - [x] Решена полностью
   - Живой прогон по Кирову: 283 объявления в Neon, 0 ошибок парсинга на квартирах.
   - Медиана 2-комн. 45 м² по свежим данным: ~5.7 млн, коридор 4.94-6.41 млн.

4. **Что можно было сделать лучше:**
   - Сразу заложить реконнект к Neon: первый прогон упал, потому что соединение простаивало во время обхода.
   - Сразу исключить комнаты/дома/гаражи из квартирной выборки по `rooms`, иначе "в 9-к." попадает как 9-комнатная квартира.
   - Проверять URL категорий по одной странице до полного обхода.

5. **Что нового узнали о проекте или окружении:**
   - Neon закрывает простаивающие соединения; любые длинные паузы между запросами требуют lazy reconnect.
   - В `analog_listings` нет уникального индекса `(source, source_id)`, поэтому upsert сделан через SELECT + UPDATE/INSERT.
   - `api/ai-proxy.js` и FastAPI-бэкенд смотрят в разные базы (`NEON_DATABASE_URL` против `DATABASE_URL`); парсер пишет в Neon.
   - `.notes/log.md` хранится в CP1251, хотя AGENTS.md требует UTF-8 - при правке файла это надо учитывать.
