# Ретроспектива сессии: 2026-11-12_ad-generator-fallback

1. **Какая задача стояла:**
   - Пользователь сообщил: "генератор объявления не работает". Нужно было найти причину и восстановить работоспособность генератора в карточке объекта.

2. **Как решали:**
   - Проверили клиент `src/utils/adGenerator.js`, компонент `AdGenerator.jsx` и серверный `api/ai-proxy.js` - код был исправен.
   - Вызвали AI-провайдеров напрямую с ключами из `.env` без вывода секретов: Gemini вернул `402 RESOURCE_EXHAUSTED` (prepayment credits depleted), OpenModel - `402 insufficient balance`, Zhipu - `429 1113` (余额不足). Все три баланса исчерпаны.
   - Добавили в `adGenerator.js` экспортируемую функцию `buildFallbackAd()`, которая собирает объявление из данных карточки по той же структуре, что и AI-промпт: заголовок, цена, О доме, О квартире/комнате/доме, Инфраструктура, Документы, Особенности, контакты риелтора.
   - При ошибке прокси, пустом ответе ИИ или недоступности сети генератор возвращает `{ text, source: 'template' }`. Ошибки авторизации (401/403) по-прежнему показываются пользователю, чтобы не маскировать истёкшую сессию.
   - В `AdGenerator.jsx` добавлен источник результата и предупреждение: "ИИ-провайдеры временно недоступны, текст собран по шаблону...".
   - Добавили unit-тесты `src/utils/adGenerator.test.js` на полный текст и на студию без адреса.
   - Попутно убрали неиспользуемые константы ключей и исправили пустой `catch`, из-за которых падал ESLint в этом файле.

3. **Результат:**
   - [x] Решена полностью
   - [ ] Решена частично
   - [ ] Не решена (причина)

4. **Что можно было сделать лучше:**
   - Сразу проверять балансы провайдеров, а не только код: ошибка была инфраструктурной, а не логической.
   - Для AI-функций заранее предусматривать деградацию до шаблона, чтобы внешний биллинг не блокировал базовый сценарий.

5. **Что нового узнали о проекте или окружении:**
   - Локальный `npm run dev` использует ключи из `.env` через `scripts/api-dev-server.mjs`, поэтому нулевые балансы воспроизводятся и локально, и на Vercel.
   - Правило для AGENTS.md: при исчерпании лимитов всех AI-провайдеров генератор объявления должен отдавать шаблонный текст, а не ошибку.
