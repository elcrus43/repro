# REA CRM — Инструкции для Claude Code

@AGENTS.md

## Специфика сессий Claude Code

### 1. Порядок чтения в начале сессии
1. `AGENTS.md` — стек, команды, правила LF, безопасность.
2. `.notes/index.md` — архитектура и текущие решения.
3. Зона задачи (`src/`, `api/` или схема БД).

### 2. Сборка и качество
- Перед завершением любой задачи обязательно проверять:
  ```bash
  npm run lint
  npm run build
  ```
- Следить за окончаниями строк: файлы строго в **LF**, UTF-8.

### 3. Рефлексия
- В конце содержательной работы фиксировать итог в `retrospectives/YYYY-MM-DD_*.md` по шаблону `retrospectives/template.md`.
