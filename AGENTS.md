# AGENTS.md — Навигация и правила проекта Realtor Match (REA CRM)

Этот документ — карта проекта для AI-агентов (Codex, Cursor, Copilot, Claude Code, Gemini).
Держи файл в пределах 100-140 строк.

## 1. Что это за проект
- **Realtor Match (REA CRM)** — специализированная мобильная и веб-CRM для риелторов и агентств недвижимости.
- **Ключевой функционал:** подбор объектов, совпадения клиентов и объектов (match engine), работа с базой данных, валидация адресов, мобильное приложение (Capacitor/Android).

## 2. Стек технологий
| Уровень | Технологии |
|---|---|
| Frontend | React 19 + Vite 7.3 + React Router v7 |
| Стилизация | Vanilla CSS (премиальный дизайн, строгая адаптивность под смартфоны) |
| Backend & DB | Supabase (PostgreSQL + Realtime) |
| Мобильная среда | Capacitor (Android) |
| AI-интеграция | Zhipu AI (GLM-4-Flash / GLM-4V-Flash) |
| Гео / Валидация | DaData API (подсказки через КЛАДР/ФИАС) |

## 5. Конституция проекта и табу (след от ошибок)
1. **Строго LF и UTF-8 (Критично для Windows):**
   * Все файлы проекта должны иметь окончания строк **LF** (не CRLF) и кодировку **UTF-8**.
   * Проверка: `node check_all_crlf.mjs`, исправление: `node fix_all_crlf.mjs`.
2. **Безопасность Supabase и .env:**
   * Секретные ключи хранятся только в `.env` (service role key никогда не должен попадать во frontend-бандл).
   * Не читать `.env` целиком.
3. **Дисциплина Git:**
   * Стейджить файлы поимённо: `git add <file>`. Избегать `git add .` без проверки.
   * Типографика: в интерфейсе и текстах — строго дефис `-`, без длинных тире `—`.
4. **Отказоустойчивость ИИ:**
   * Если все AI-провайдеры вернули ошибку баланса или лимитов, генератор объявления должен отдавать шаблонный текст по данным карточки, а не ошибку.
5. **Секреты AI-провайдеров:**
   * Ключи Gemini/OpenModel/Zhipu хранить только в серверных переменных без префикса `VITE_`, иначе они попадут в клиентский бандл.
